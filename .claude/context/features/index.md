# Features

Grouped by area. Each file is a confirmed spec: what the feature is for, a per-persona matrix, and two or three entry points into the code.

Only documented features are listed. A feature with no doc here has not been documented yet; `/applied-product:context-init` lists the undocumented ones on every re-audit.

## Find By
- **Area** → folders below
- **Code path** → grep the path across feature files (each names its entry points)
- **Persona** → `personas/<persona>.md` lists features they use
- **Tag** → grep `tags:` across docs for cross-cutting concerns (e.g. `pii`, `stripe`, `admin`)
